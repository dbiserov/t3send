# Send to T3 demo

A 30-second animated demo of the Send to T3 browser add-on: start a T3 thread from an email, link a Slack message to the same thread, settle it in T3 and see both marked done.

Watch it: https://dbiserov.github.io/send-to-t3-demo/

People, companies, links and IDs in the demo are made up. The Inter font is under the SIL Open Font License (inter-OFL.txt).
